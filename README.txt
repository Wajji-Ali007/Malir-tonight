MALIR TONIGHT RESTAURANT — WEBSITE DEMO
========================================

Files:
- index.html: responsive single-page demo website with hover animations and food photos
- assets/: customer-provided menu photos for reference

How to preview:
1. Extract the ZIP.
2. Open index.html in a browser.

Important before sharing with the restaurant:
- This is a proposal/demo, not an official restaurant website.
- Menu items/prices have been transcribed from supplied photos; some prices are unclear and must be verified.
- Phone/WhatsApp numbers and address were taken from the supplied menu image. Please confirm they are correct.
- Replace the decorative food illustration with approved restaurant/food photography if available.
- To make a public link, upload the extracted files to a static host such as Netlify Drop or GitHub Pages. No backend is required for this demo.

Note: Menu card food photos load from Unsplash and require an internet connection.
